## LDAP Client Library (Java/JNDI, 2010)

A small LDAP client module supporting SSL connections, directory search, and attribute updates via JNDI. Originally developed as part of an internal company tool with a Swing GUI; this repository contains the backend integration code, extracted and reorganized into separate classes for configuration, connection handling, and directory operations.

Note: the class-based structure was a client requirement at the 
time — not my natural approach to organizing this kind of logic, 
but a useful lesson early in a long-standing preference for 
simpler, procedural code.
